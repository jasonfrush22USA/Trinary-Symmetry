Binary Prime Indicator Function 1_P(360k + R)

Plots raw output: 1 (Prime / No hyperbola lattice solution) vs 0 (Composite / Hyperbola lattice solution found).

Mathematical Framework

The indicator function evaluates integers of the form N = 360k + R, where R represents a residue coprime to the base modulus 360 = 23 × 32 × 5 (often visualised as a radial spoke on a 360-degree wheel). By restricting structural evaluation to spokes where gcd(R, 360) = 1, all trivial multiples of 2, 3, and 5 are filtered out automatically.

A composite candidate on spoke R exists if and only if N can be factored into A × B = (360x + Ra)(360y + Rb), where (Ra × Rb) ≡ R (mod 360). Geometrically, this transformation projects potential factors onto integer lattice points lying along hyperbolic curves. When no non-trivial integer lattice solution (x, y) intersects the hyperbola corresponding to 360k + R, the indicator yields 1P(N) = 1 (Prime); otherwise, the presence of a valid lattice point causes 1P(N) to collapse to 0 (Composite).
